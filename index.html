3. 入力とボタンを設定

各入力に ↑・↓・←・→・A・B・なし を割り当てます。設定はこのブラウザに保存されます。

アナログは数値の3範囲、デジタルはONに対応します。OFFやデータ途絶時は解除。同じボタンに複数入力を割り当てた場合は、どれかがONなら押したままになります。最大12入力。

M5GOの準備（UIFlow 1・ブロック）

  1. ToF距離センサーをM5GOのPort Aにつなぎます。
  2. UIFlow 1のブロック画面で、使用する機種を選び、UnitsにToFを追加してPort Aを指定します。
  3. 下の表からブロックを取り出し、その下の組み立て手順に沿ってつなぎます。

使うブロックと場所

日本語表示のUIFlow 1に合わせた名称です。［ ］は入力欄、▼は選択欄を表します。

場所画面で探すブロック使い方・見分け方
イベントずっと内側に処理を入れるブロック。Setupの下につなぎ、今回の処理をすべて内側に入れます。
テキスト［ ］をシリアル出力するオレンジ色。「［ ］の長さ」の下にあるブロック。これを3個使います。以前の説明の「print」は、このブロックのことです。
テキスト“［ ］”一番上の、文字を入力するブロック。「(unescaped)」付きではない方です。下に示す文字を入力します。
テキスト［ ］＋［ ］「テキストに変換する」の下にあるオレンジ色の＋。2個使って3つの値をつなぎます。数値も文字に変換されるので、別の変換ブロックは不要です。
Units → ToF［tof_0 ▼］と測定物との距離[mm]を読み込む先にToFをPort Aとして追加します。tof_0の部分は追加したユニットの名前です。
論理もし［ ］であれば
そうでなければ		歯車から「else」を追加して「そうでなければ」の段を作ります。最初からその段があるものは、そのまま使えます。
イベントボタン［A ▼］が［pressed ▼］である「もし」の条件欄に入る、状態を調べるブロック。Aとpressedを選びます。「ボタンAが押されたとき」というイベント開始ブロックは使いません。
タイマー［50］[ミリ秒]停止数値を50にします。「[秒]停止」と区別してください。秒のブロックを使う場合は0.05を指定します。

1. 距離を送るブロックを組む

  1. 「［ ］＋［ ］」を2個取り出し、1個目の左の穴に2個目を入れます。
  2. 内側の＋の左に “［ ］” を入れて {"distance": と入力し、右に「［tof_0 ▼］と測定物との距離[mm]を読み込む」を入れます。
  3. 外側の＋の右に “［ ］” を入れて } と入力します。
  4. できた＋のかたまりを「［ ］をシリアル出力する」の穴に入れます。
［ ［ “ {"distance": ” ＋ ［ToFの距離ブロック］ ］ ＋ “ } ” ］をシリアル出力する

図の外側の “ ” はブロックにもともと描かれている引用符です。入力する文字は {"distance": と } だけです。distanceを囲む半角の " は必要です。

2. 本体Aボタンを送る処理と待ち時間を追加する

「もし」の条件に「ボタン［A ▼］が［pressed ▼］である」を入れます。「であれば」と「そうでなければ」に、それぞれ「［ ］をシリアル出力する」を入れ、テキストを下のとおり設定します。

ずっと
 ├ ［1で組んだ距離の文字列］をシリアル出力する
 │
 ├ もし［ボタン［A ▼］が［pressed ▼］である］であれば
 │    ［ “ {"buttonA":1} ” ］をシリアル出力する
 │  そうでなければ
 │    ［ “ {"buttonA":0} ” ］をシリアル出力する
 │
 └ ［50］[ミリ秒]停止

ボタンを離している間の {"buttonA":0} も毎回送ります。組み上がったら、以下の手順でWebページにつなぎます。

  1. 組んだブロックのプログラムをM5GOにダウンロードして実行します。
  2. UIFlow側のUSB接続やシリアルモニターを閉じ、このページの「USB接続」でM5GOのポートを選択します。
  3. 「M5GO（USB）」を選び、入力名を確認します。距離は distance（アナログ）、本体Aボタンは buttonA（デジタル）です。
  4. 各入力のボタンを割り当て、「入力を開始／再開」を押します。設定を変更した場合も、もう一度「入力を開始／再開」を押します。

PCへの中継アプリのインストールは不要です。M5GOがPCで認識されるUSBドライバーと、UIFlow 1のファームウェアは必要です。USBでの実機動作は未確認です。

現在値の更新が遅いとき

各入力の「前回との受信間隔」は、ブラウザにその入力のデータが届いた間隔です。同じ値でも受信回数は増えます。USBでまとめて届いた場合は短い間隔になるため、センサー自体の測定時間とは限りません。

  • 間隔が1000 ms程度以上なら、UIFlowの「停止」ブロックの数値と単位を確認してください。指定は「50 [ミリ秒]停止」です。「50 [秒]停止」ではありません。
  • 待ち時間を短くするには「10 [ミリ秒]停止」で試せます。ただしToFの測定時間も加わるため、10 msごとに必ず更新されるわけではありません。
  • 受信回数が増えているのに値が変わらない場合は、距離の読み取りブロックが「ずっと」の内側に入っているか確認してください。
ゲームの作り方・通信仕様

Arcadeでは通常の「コントローラーでスプライトを動かす」や「Aボタンが押されたとき」を使います。保存後に「共有」でURLを作り、上の欄へ貼り付けます。編集後は必要に応じて再共有してください。

USBは115200 bps。上のブロックは、距離を {"distance":150}、本体Aボタンを {"buttonA":1} または {"buttonA":0} として、別々の行で繰り返し送ります。1行にまとめて {"distance":150,"buttonA":1} と送る形式にも対応しています。

入力名を設定欄と一致させてください。distance はmm、ほかのアナログ入力は送信する数値の単位で境界を設定します。デジタルは 1 / true がON、0 / false がOFFです。OFFの値も必ず送ってください。各入力は1秒以上更新されないと解除されます。

追加のセンサーを使う場合は、UIFlow側にも読み取りと「［ ］をシリアル出力する」のブロックを追加します。ページを離れたときは入力を解除します。戻ったら「入力を開始／再開」を押してください。

MakeCodeのシミュレーターへのメッセージ送信を利用しています。公式サービス側の変更で調整が必要になる場合があります。
