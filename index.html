M5GO × MakeCode Arcade

センサーやスイッチを、Arcadeの操作ボタンに割り当てます。

1. ゲームを読み込む

まずは動作確認用ゲームで試せます。

2. 入力を選ぶ

未接続 · Chrome / Edgeを使用してください。

3. 入力とボタンを設定

各入力に ↑・↓・←・→・A・B・なし を割り当てます。設定はこのブラウザに保存されます。

アナログは数値の3範囲、デジタルはONに対応します。OFFやデータ途絶時は解除。同じボタンに複数入力を割り当てた場合は、どれかがONなら押したままになります。最大12入力。

ゲームへの入力停止

入力は停止中です。

M5GOの準備（UIFlow 1）

  1. ToF距離センサーをM5GOのPort Aにつなぎます。
  2. 送信用プログラムをダウンロードし、UIFlow 1のPython画面に貼り付けてM5GOで実行します。
  3. UIFlow側のUSB接続やシリアルモニターを閉じ、このページの「USB接続」でM5GOのポートを選択します。
  4. 「M5GO（USB）」を選び、「入力を開始／再開」を押します。距離は distance、本体Aボタンは buttonA として届きます。

PCへの中継アプリのインストールは不要です。M5GOがPCで認識されるUSBドライバーと、UIFlow 1のファームウェアは必要です。実機での確認前の試作版です。

ゲームの作り方・通信仕様

Arcadeでは通常の「コントローラーでスプライトを動かす」や「Aボタンが押されたとき」を使います。保存後に「共有」でURLを作り、上の欄へ貼り付けます。編集後は必要に応じて再共有してください。

USBは115200 bps。1行ごとに {"distance":150,"buttonA":1} のようなJSONを送ります。入力名を設定欄と一致させてください。distance はmm、ほかのアナログ入力は送信する数値の単位で境界を設定します。デジタルは 1 / true がON、0 / false がOFFです。各入力は1秒以上更新されないと解除されます。追加のセンサーを使う場合は、M5GOの送信プログラムにも読み取りと送信項目の追加が必要です。ページを離れたときも解除し、戻ったら入力を再開してください。

MakeCodeのシミュレーターへのメッセージ送信を利用しています。公式サービス側の変更で調整が必要になる場合があります。
